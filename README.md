# MiniCapture

[https://gitee.com/fusheng_zhang/mini-cap](https://gitee.com/fusheng_zhang/mini-cap)
[https://github.com/fushengruomengzhang/MinCap](https://github.com/fushengruomengzhang/MinCap)

轻量 macOS 菜单栏截图 / 录屏工具。支持就地标注、复制、保存、钉图；另有录屏与 GIF。

## 要求

- macOS 15+
- Apple Silicon（arm64）

## 功能概览

| 能力 | 说明 |
|------|------|
| 截图 | 微信风格框选，窗口吸附，就地标注 |
| 标注 | 矩形 / 圆形 / 三角形 / 六边形、箭头、画笔、马赛克、文字等 |
| 结果 | 复制到剪贴板、保存文件、钉在桌面 |
| 录屏 | 区域录屏（可选麦克风） |
| GIF | 录制为 GIF |
| 长截图 | 选区内自动滚动拼接 |

## 快捷键（默认）

| 功能 | 快捷键      |
|----|----------|
| 截图 | ⌘ + `.`  |
| 录屏 | ⌥ + `.` |

快捷键可在 **菜单栏 → 设置** 中自行绑定。修饰键不区分左右。

## 权限

首次使用请授予：

- **屏幕录制**
- **辅助功能**（按系统提示）

部分系统版本还需在「系统设置 → 菜单栏」允许显示菜单栏图标。

## 安装 DMG

1. 双击 `.dmg`
2. 将 `MiniCapture.app` 拖到「应用程序」
3. 在「应用程序」中打开 MiniCapture
4. 若提示无法验证开发者：关闭弹窗 → **系统设置 → 隐私与安全性 → 仍要打开**
5. 按提示授予屏幕录制等权限，查看菜单栏右侧 MC 图标
